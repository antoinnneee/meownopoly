Audit V2 → cible V3 · M1 à M13

Réutiliser le socle, ajouter les garanties manquantes.

La V2 possède déjà l’éditeur, le P2P, la physique et la distribution. La V3 ne les remplace pas : elle ajoute une couche d’autorité, d’isolation, d’observabilité et de contrat public.

Point d’attentionreliable.io acquitte et fragmente, mais ne retransmet pas automatiquement. La fiabilité forte doit être construite au niveau applicatif V3.

Lecture par état

Réutilisé · modifié · nouveau

● Réutilisé

Fondations éprouvées

  • Qt/QML/C++ et CMake
  • ItemSnapable + sérialisation
  • EditorOpBus / EditorSession
  • Catway / STUN / P2P
  • Pattounx / PhysicsSession / World3D

● À étendre

Contrats insuffisants

  • Transactions groupées → atomiques
  • ACK transport → retry applicatif
  • Map save → sauvegarde de partie
  • Full-sync → hash + resync
  • Launcher → supervision d’agents
  • Assets → version/hash/package
● Nouveau

Briques propres à V3

  • Passerelle MCP streamable HTTP
  • Enveloppe de proposition
  • IA arbitre et handshake
  • Banc d’essai hors-process
  • Confinement QML/JS runtime
  • Bus d’événements et d’état générique
  • Store d’artefacts par hash
